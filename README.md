## 🧠 Problems Solved

### Day 01: Kids With the Greatest Number of Chocolates

**Topic:** Arrays

**Approach:**

1. Find the maximum number of chocolates among all children.
2. Add the extra chocolates to each child's current count.
3. Compare the new count with the maximum.
4. Store `true` if the child can have the greatest number of chocolates; otherwise, store `false`.

**Time Complexity:** O(n)

**Space Complexity:** O(n), including the returned boolean array.

---

### Day 02: Merge Strings Alternately

**Topic:** Strings / Two Pointers

**Approach:**

1. Use an index `i` to access characters in both strings.
2. Append the character from the first string if available.
3. Append the character from the second string if available.
4. Continue until both strings have been processed.

**Example:**

```text
Input:
abc
pqr

Output:
apbqcr
```

**Time Complexity:** O(n + m)

**Space Complexity:** O(n + m), including the resulting string.

Here, `n` and `m` represent the lengths of the two input strings.
